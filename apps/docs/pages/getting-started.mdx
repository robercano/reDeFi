# Getting Started

To get started with ReDeFi SDK, you will need a few things set up.

1. Ensure you have `pnpm` installed.
2. Install the core SDK packages.

```bash
pnpm install @thesolidchain/sdk-client
```

## Quick Example

```typescript
import { createReDeFiClient } from '@thesolidchain/sdk-client'

const client = createReDeFiClient({
  // your config
})
```
