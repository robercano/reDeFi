# Welcome to ReDeFi SDK

The **ReDeFi SDK** is a powerful toolkit for integrating decentralized finance protocols into your applications.

## Getting Started

To install the SDK, run:

```bash
pnpm install @thesolidchain/sdk-client
```

## Features

- **Yield Simulators:** Simulate DeFi strategies instantly.
- **Protocol Plugins:** Out-of-the-box support for Aave, Maker, Spark, Morpho, and more.
- **Intent-based Actions:** Send high-level intents instead of raw transactions.
