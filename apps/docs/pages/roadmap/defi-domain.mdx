# 2. DeFi Domain & Portfolio Aggregation

## Comprehensive Portfolio Manager (`IPortfolio`)
**Goal:** A single holistic view of a user's net worth and active positions.  
**Approach:**
1. Implement the `IPortfolio` interface containing `walletHoldings`, `yieldPositions`, `stakingPositions`, and `debtPositions`.
2. Expose methods to calculate aggregate USD value using integrated Oracles.
3. Track historical PnL by comparing current value against imported transaction history.

## Standardized Yield & Vault Integrations (ERC-4626)
**Goal:** Plug-and-play support for yield-bearing assets.  
**Approach:**
1. Create a base `ERC4626Plugin` that conforms to the SDK's `ILendingProtocol` interface.
2. Use `convertToShares` and `previewDeposit` standard ABI functions.
3. For non-standard protocols (like Aave V3), create specific plugins that map their custom logic to the ERC-4626 style inputs/outputs in the SDK.

## Oracle Integration Expansion
**Goal:** Reliable, manipulation-resistant asset pricing.  
**Approach:**
1. Create an `IOracleProvider` interface.
2. Implement plugins for CoinGecko (REST API), 1inch (Spot Price API), and Chainlink (On-chain Aggregators).
3. The `PortfolioManager` will query these oracles to resolve token amounts to Fiat equivalents.
