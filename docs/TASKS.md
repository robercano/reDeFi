# ReDeFi SDK Tasks

The reDeFi SDK has a well defined architecture and any tasks must comply with this architecture and
try to adhere to it as much as possible. If for any tasks it is not clear how to adhere to the
architecture you must ask me for advice. You can find the architecture description in the
ARCHITECTURE.md file in this same directory.
